## 1. サービス概要

「GaMu：ゲーミュ」は、作業用ゲーム音楽アプリです。
ゲーム音楽を知らない人がこの作業用アプリを通じてゲーム音楽を好きになってもらうようなアプリです。

## 2. このアイデアはどこから生まれたか

### 2-1. きっかけとなった体験・感情

私はゲーム音楽が大好きでプレイ済でも未プレイでも関係なく聴きます。
学習など何か作業をする場合にも必ずゲーム音楽を流して作業します。
ただし、普段ゲームをしない人はあまりゲーム音楽はなじみがないものだと思います。
ゲームをする人でも、あくまで自分がプレイしたことがあるゲームの音楽を聴くぐらいではないでしょうか。
そうした中でもっと多くの人にゲーム音楽に触れる機会があればと考えました。

### 2-2. なぜそれが「気になった」のか

ゲーム音楽というものはあくまでそのゲームをプレイした人が聴くものという印象があるのではないでしょうか。
もちろんゲーム中に流れるものであるためゲームプレイとの結びつきが非常に強いです。
ですが音楽単体で聴いても良い曲が多く、
ゲームを知らなくても、単体のBGMとしてもっと多くの人に聴かれてもいいのではと思っています。

## 3. 課題の整理（表面的になっていないか）

### 3-1. 表に見えている困りごと

作業用のBGMを探す際に、ゲーム名や曲名を知らない人にとってはゲーム音楽を探すことが難しく、
ゲーム音楽に触れる機会が少ないことです。

### 3-2. 本当に解決したい課題は何か

ゲーム名や曲名を知らない人でも、作業用BGMとして気軽にゲーム音楽を聴けるようにしたいです。
曲調を選択するだけでその曲調に合ったゲーム音楽がランダムに流れます。
ゲームをしない人にもゲーム音楽を聴いてもらいたいと思います。

## 4. 想定ユーザーについて

### 4-1. 想定しているユーザー

生活・状況設定：
- 作業中にBGMを流すが、毎回BGMを探すことに疲れている人を想定しています。

### 4-2. 自分とユーザーの距離

身近な誰か：
- 家族や友人など身近な誰か
ゲームをしない家族や友人などに使ってほしいと思います

### 4-3. 実際に使われる可能性について(需要・存在確認)

まず最初に使ってくれそうな人は誰か？：
- まず友人に使ってもらいます。

その人は、どんな場面でこのアプリを思い出すか？：
- 学習中や家事など何か作業を行っている際に思い出します。

今の生活の中で、代わりに使っているものは何か？：
- 友人は普段作業するときは、検索をするのが面倒なので、YouTubeのおすすめに出てくる作業用BGMを流しています。
おすすめにない時は「BGM」「作業用BGM」な検索して出てきたものを聴いています。

それを置き換えてまで使う理由はあるか？：
- ゲーム名や曲名を検索する必要がなく、作業を始めると同時にランダムでゲーム音楽を聴けるため、
BGMを探す手間を減らすことができます。

### 4-4. ユーザーがサービスを導入して利用するまでのイメージ(導入・継続の流れ)

どんな場面・困りごとがきっかけで、このサービスを知る・思い出すか：
- 作業用BGMを探している人がこのサービスを思い出すと思います。

最初の一歩（登録・導入）で、ユーザーは何をする必要があるか：
- ユーザー登録は不要で、アプリにアクセスして曲を再生する、もしくはポモドーロを開始するだけで利用できます。

利用を続ける理由は何か？（習慣・必要性・価値）
- ゲーム音楽にハマってもらうことで学習や作業時に習慣的に利用してもらいます。

## 5. 既存サービス・競合調査

### 5-1. 似たサービスの調査

最低1つは調べてください。

- サービス名：YouTube
- URL：https://www.youtube.com/
- どんなことができるか：動画共有サイト最大手。様々なゲーム音楽があり、音楽用のYouTube Musicもあります。

- サービス名：Spotify
- URL：https://open.spotify.com/intl-ja
- どんなことができるか：音楽配信・リスニングサービス。ゲーム音楽なども多数配信されています。

- サービス名：Nintendo Music
- URL：https://music.nintendo.com/ja-JP/
- どんなことができるか：任天堂のゲーム専用のミュージックアプリ。「リラックスできる曲」などテーマ別のプレイリストなどもあります。

### 5-2. それでも自分が作りたい理由

既存サービスがある中で、
なぜ満足できなかったのか：
- YouTubeやSpotify、Nintendo Musicでもゲーム音楽を聴くことはできます。
ですが、本サービスではゲーム名や曲名を知らなくても曲調を選ぶだけでゲーム音楽がランダムで再生されます。
ゲーム音楽を「探す」のではなく、「作業中に自然にゲーム音楽に出会える体験」を提供することで差別化します。

- YouTubeやSpotifyなどは検索して曲やプレイリストにたどり着くまでに少し手間があります。
 「ゲーム音楽 リラックス」など検索欄に入力してそこから表示されるプレイリストや曲を選んで決定する必要があります。

### 5-3. 差別化を「体験価値」で表現する

私のアプリの差別化ポイント：
1. 作業用のミュージックアプリとしてゲーム音楽に特化しています。
2. 検索をしないので検索ワードを考えて入力する必要がありません。
3. 検索結果に表示されるプレイリストや動画から選択する手間を省くことができます。
4. 任天堂のゲームタイトルに限らず幅広いタイトルの曲を用意します。

## 6. このサービスで提供したい価値

### 6-1. ユーザーの変化

このサービスを使うことで、ユーザーはどう変化しますか？

行動の変化：
- ゲーム音楽を聴いたことがなかった人がゲーム音楽を聴く頻度が増えると思います。

考え方の変化：
- ゲーム音楽も作業用BGMの選択肢の一つとして感じてもらえると思います。

### 6-2. 価値を一文で表す

「このサービスは、ゲームをプレイした人がない人でも、作業をしながらゲーム音楽に気軽に触れられるサービスです。」

## 7. このアプリで実現すること

### MVPで作る機能

- YouTubeのゲーム音楽を埋め込み、ランダム再生する機能
- 約50曲のゲーム音楽を用意
- MVPでは「落ち着いた・リラックス」に分類した曲のみを対象とする
- 利用規約・プライバシーポリシー

### 本リリースで作る機能

- 「明るい」「悲しい」など選択できる曲調を追加
- BGMが曲調にあっているかどうかユーザに評価してもらうための、合う・合わないボタンの追加
- 曲数の追加
- ポモドーロ機能の追加
- お気に入りボタンの追加
- お気に入り楽曲の一覧画面の追加
- ログイン機能の追加

## 8. このアプリの懸念点とその対策

### 懸念点①

何が問題になりそうか：
- YouTube上の動画を利用するので、動画が削除・非公開になった場合はその曲を再生できなくなる可能性があります。

なぜそう思うか：
- 自分でBGMを用意することはできないため、どうしてもYouTubeの投稿者に依存してしまうからです。

そのために考えている対策：
- 利用できなくなった場合は別の曲に差し替える対応を行います。

### 懸念点②

何が問題になりそうか：
- ゲーム音楽の選定に時間がかかることです。

なぜそう思うか：
- 私自身がBGMを選定し、曲調を分類するので曲数が多いと作業時間が膨大になります。

そのために考えている対策：
- MVPでは最低限サービスとして成立するような曲数として約50曲用意したいと考えています。

## 9. 今後の展開・発展の方向性

ユーザーはなぜ使い続ける？
- BGMを毎回探す必要がなく、再生ボタンを押下するかポモドーロを開始するとすぐに音楽を再生できることに加え、
ランダム再生によって新しいゲーム音楽に出会えるためです。

続けることで何が変わる？
- 様々なゲーム音楽を聴くことでゲーム音楽を好きになってもらうことができると思います。
そしてもっと多くの曲を聴いてもらうことができます。

データが溜まると何ができる？
- 曲調に対してユーザー評価ボタンを実装できれば、どのようなBGMが好まれているかや曲調にあっていると感じてもらえるのかがわかります。
そのデータをもとにユーザーの好みに合った曲を追加ができると思います。

他の人と関わる余地はある？
- 再生中の曲をSNSなどに投稿する機能を追加することで、ユーザー同士がゲーム音楽を知るきっかけを作れると考えています。

運用・仕組みで価値を出せないか？
- BGM単体からそのゲームタイトル全体の音楽に興味を持ってもらい、再生中の曲からゲーム作品や公式のサウンドトラックの情報へ遷移させる機能を追加することで、楽曲だけでなく作品そのものにも興味を持ってもらえる可能性があります。

### 今考えている発展案

機能追加の方向性：
- 曲数の追加や曲調の追加を行いたいです。
- ユーザー評価ボタンを追加してよりユーザーの好みに特化したBGMを追加していきたいです。


## 10. 技術スタック（手段としての技術）

言語：

開発環境：
- Docker

### 10-2. 技術選定の比較検討

| 候補 | 採用/不採用 | 理由 |
| --- | --- | --- |
| React | 不採用 | Reactを利用するほどの機能は不要のため不採用 |
| Hotwire（Turbo / Stimulus） | 採用 | ポモドーロタイマーなどの実装のために採用 |
| YouTube IFrame Player API | 採用 | YouTube動画の再生・停止など操作を実装するために採用 |
| YouTube Data API | 不採用 | YouTubeの動画検索やタイトル、チャンネル情報などの取得が可能だが、曲は検索ではなくあらかじめ登録するため不採用 |
| Neon | 採用 | 無料枠があり、ミニアプリ開発でも使用した経験があるため採用 |
| Render | 採用 | ミニアプリ開発で使用した経験があるため採用 |
